# TBK-Clicker v2.2

Профессиональный десктопный автокликер для Windows с графическим интерфейсом на базе **CustomTkinter**, низкоуровневой эмуляцией через **Windows API** (`ctypes`), сквозным визуальным маркером цели и поддержкой клавиатурного спамера.

---

## Возможности приложения

### 1. Режим кликера мыши (Mouse Clicker)
- **Сквозной плавающий маркер:**
  - При создании на экране появляется круглый прицел поверх всех окон (`topmost=True`).
  - В режиме покоя маркер свободно перетаскивается мышью в любую точку экрана.
  - При запуске кликера маркер автоматически переходит в сквозной режим (`WS_EX_TRANSPARENT`): клики физически проходят сквозь окно маркера и попадают непосредственно в папки, окна или игры под ним.
  - Доступна ручная фиксация маркера кнопкой переключения режима.
- **Поддержка двойного клика (Double Click):**
  - Выбор режима: «Одиночный (Single)» или «Двойной (Double)».
  - В режиме двойного клика эмулируется два быстрых нажатия с паузой 40 мс, что обеспечивает гарантированное открытие папок и ярлыков в проводнике Windows.
- **Выбор кнопки мыши:**
  - Левая кнопка (LMB) или Правая кнопка (RMB).
- **Клик без маркера:**
  - Если маркер удален, клики выполняются в текущей позиции курсора.

### 2. Режим клавиатурного кликера (Key Presser)
- Циклический спам любой назначенной клавиши (`Enter`, `Пробел`, `E`, `1` и др.).
- Эмуляция нажатия на уровне Windows API (`keybd_event`) с виртуальными кодами клавиш (VK).
- В данном режиме экранный маркер автоматически отключается и скрывается.

### 3. Регулировка скорости и синхронизация
- Поля «Интервал (сек)» и «Действий/сек (CPS)».
- Автоматический мгновенный пересчет значений (`CPS = 1 / Interval`, `Interval = 1 / CPS`) с защитой от циклической рекурсии.

### 4. Глобальный хоткей активации (Start / Stop Toggle)
- Динамическое назначение любой клавиши на клавиатуре (по умолчанию `F6`).
- Режим переключателя (Toggle): первое нажатие запускает цикл, повторное — останавливает.
- Глобальное срабатывание поверх полноэкранных игр и свернутых окон через `pynput.keyboard`.

### 5. Архитектура и надежность
- Строгая объектно-ориентированная архитектура (ООП) с изоляцией логики от графического интерфейса.
- Фоновый изолированный поток (`threading.Thread`, daemon) с мгновенной реакцией на остановку (`threading.Event`).
- Отсутствие утечек системных дескрипторов Windows и мгновенный выход из приложения.

## Установка и запуск из исходного кода

### 1. Переход в папку проекта
```bash
cd "TBK-Clicker/TBK-Clicker Project"
```

### 2. Создание и активация виртуального окружения
```bash
python -m venv .venv
# Для Windows PowerShell:
.venv\Scripts\Activate.ps1
# Для Windows CMD:
.venv\Scripts\activate.bat
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск приложения
```bash
python main.py
```
*(Либо в PyCharm: правой кнопкой мыши по `main.py` -> **Run 'main'**)*.

## Сборка в автономный файл (.exe)

Приложение упаковывается в единый бинарный `.exe` файл без консольного окна с помощью **PyInstaller**.

### Вариант 1. Сборка скриптом
Запустите файл `build.bat` внутри папки `TBK-Clicker Project`:
```cmd
build.bat
```

### Вариант 2. Сборка через консоль
```bash
pyinstaller --noconsole --onefile --clean --collect-all customtkinter --name "TBK-Clicker" main.py
```

Готовый файл размещается по пути:
```text
TBK-Clicker Project/dist/TBK-Clicker.exe
```

## Руководство по использованию

1. **Выбор режима:**
   - В верхней части окна выберите **«Режим Мыши»** или **«Режим Клавиатуры»**.
2. **Настройка скорости:**
   - Задайте желаемый **Интервал** (например, `0.05`) или **CPS** (например, `20`).
3. **Для режима мыши:**
   - При необходимости нажмите **«Добавить маркер на экран»** и перетащите кружок на целевую папку, кнопку или окно.
   - Выберите кнопку (ЛКМ / ПКМ) и тип нажатия (Одиночный / Двойной).
4. **Для режима клавиатуры:**
   - Нажмите **«Назначить целевую клавишу»** и нажмите нужную клавишу на клавиатуре (например, `Enter` или `Пробел`).
5. **Запуск и остановка:**
   - Нажмите назначенную клавишу на клавиатуре (по умолчанию `F6`) или кнопку **«Старт»** в интерфейсе.
   - Для остановки нажмите ту же клавишу повторно или кнопку **«Стоп»**.
