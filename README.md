# TBK-Clicker v2.0 ⚡

Современный, сверхбыстрый и надежный desktop-автокликер для Windows с графическим интерфейсом на базе **CustomTkinter**, плавающим визуальным маркером цели (**Drag & Drop Toplevel**), низкоуровневой симуляцией кликов через **Windows API** (`ctypes`) и глобальным перехватом клавиш (**pynput**).

---

## ✨ Основные возможности

- 🎯 **Плавающий визуальный маркер цели (Drag & Drop):**
  - Кнопка **«🎯 Добавить маркер на экран»**: поверх всех окон появляется круглый полупрозрачный неоновый прицел (`overrideredirect(True)` + `topmost=True`).
  - Маркер можно свободно зажать левой кнопкой мыши и перетащить в любую точку экрана.
  - Кликер автоматически считывает экранные координаты центра этого кружка и выполняет клики точно по цели.
  - Если маркер не добавлен/удален — клики выполняются **в текущей позиции курсора**.
- ⌨️ **Гибкое назначение клавиши (Keybind Start/Stop Toggle):**
  - Кнопка **«Назначить клавишу»**: при нажатии переходит в режим ожидания — первая нажатая клавиша на клавиатуре становится активным хоткеем.
  - Работает как **Toggle** (нажал — включил, нажал еще раз — выключил).
  - Глобальное срабатывание поверх полноэкранных игр и свернутых окон через `pynput.keyboard`.
  - Корректная поддержка любых раскладок (русская/английская) и специальных клавиш (F1–F12, Space и т.д.).
- ⚡ **Двусторонняя синхронизация скорости (Интервал ⇄ CPS):**
  - Поле «Интервал (сек)» с поддержкой дробных чисел (`0.1`, `0.05`, `0.01` и т.д.).
  - Поле «Кликов/сек (CPS)».
  - Мгновенный автоматический пересчет (`CPS = 1 / Interval` и `Interval = 1 / CPS`) с защитой от циклических событий пересчета.
- 🖱 **Тип клика:**
  - Выбор кнопки мыши через выпадающий список: **Левая кнопка (LMB)** или **Правая кнопка (RMB)**.
- 🚀 **Максимальная надежность кликов (WinAPI):**
  - Прямая симуляция через системный `ctypes.windll.user32.mouse_event` и `SetCursorPos`.
  - Клики гарантированно доходят до целевых окон, игр и приложений без задержек.
- 🛡 **Архитектура и безопасность:**
  - Строгая объектно-ориентированная структура (ООП).
  - Фоновый изолированный поток кликов (`threading.Thread`, daemon) с мгновенной реакцией на остановку (`threading.Event`).
  - Чистое освобождение ресурсов, хуков и корректное закрытие окон (`WM_DELETE_WINDOW`).

## 🚀 Установка и запуск из исходного кода

### 1. Переход в папку проекта
```bash
cd "TBK-Clicker/TBK-Clicker Project"
```

### 2. Создание и активация виртуального окружения (рекомендуется)
```bash
python -m venv .venv
# Для Windows PowerShell:
.venv\Scripts\Activate.ps1
# Для Windows CMD:
.venv\Scripts\activate.bat
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск приложения
```bash
python main.py
```
*(Либо в PyCharm: ПКМ по `main.py` -> **Run 'main'**)*.

## 📦 Сборка в автономный исполняемый файл (.exe)

Для сборки используется **PyInstaller**. Приложение упаковывается в один `.exe` файл без консольного окна.

### Вариант 1. Через скрипт сборки (в один клик)
Запустите `build.bat` внутри папки `TBK-Clicker Project`:
```cmd
build.bat
```

### Вариант 2. Вручную через терминал
```bash
pyinstaller --noconsole --onefile --clean --collect-all customtkinter --name "TBK-Clicker" main.py
```

Готовый файл появится в каталоге:
```text
TBK-Clicker Project/dist/TBK-Clicker.exe
```

## 🎮 Инструкция по использованию

1. **Маркер цели:**
   - Нажмите кнопку **«🎯 Добавить маркер на экран»**.
   - На экране появится круглый неоновый прицел. Зажмите его левой кнопкой мыши и перетащите в нужную точку экрана.
   - Если маркер не нужен, нажмите **«❌ Удалить маркер точки»** — клики будут выполняться в позиции курсора мыши.
2. **Настройка скорости:**
   - Введите желаемый **Интервал (сек)** (например, `0.05`) или **CPS** (например, `20`). Поля пересчитаются автоматически.
3. **Назначение клавиши:**
   - Нажмите **«⌨️ Назначить клавишу»** и нажмите любую удобную клавишу (например, `F6` или `R`).
4. **Запуск и остановка:**
   - Нажмите назначенную клавишу на клавиатуре или кнопку **«▶ Старт»** в интерфейсе.
   - Для остановки нажмите ту же клавишу еще раз (Toggle) или кнопку **«⏹ Стоп»**.
