# TBK-Clicker ⚡

Современный, быстрый и надежный desktop-автокликер для Windows с графическим интерфейсом на базе **CustomTkinter**, фоновой автоматизацией **PyAutoGUI** и глобальными хуками **pynput**.

---

## ✨ Основные возможности

- 🎯 **Гибкий выбор координат клика:**
  - Ручной ввод координат `X` и `Y`.
  - **«Выбрать точку на экране»**: фоновый слушатель мыши перехватывает первый же клик в любой точке экрана и автоматически заполняет координаты.
  - Если поля `X` и `Y` пусты — клики выполняются **в текущей позиции курсора**.
  - Кнопка быстрой очистки координат.
- ⚡ **Двусторонняя синхронизация скорости (Интервал ⇄ CPS):**
  - Поле «Интервал (сек)» с поддержкой дробных чисел (`0.1`, `0.05` и т.д.).
  - Поле «Кликов/сек (CPS)».
  - Автоматический мгновенный пересчет (`CPS = 1 / Interval` и `Interval = 1 / CPS`) без зацикливания событий через флаг блокировки.
- 🖱 **Тип клика:**
  - Выпадающий список выбора кнопки мыши: **Левая кнопка (LMB)** или **Правая кнопка (RMB)**.
- ⌨️ **Глобальные горячие клавиши:**
  - **`F5`** — Запуск автокликера.
  - **`F6`** — Остановка автокликера.
  - Работают поверх любых свернутых окон, фоновых программ и полноэкранных игр.
- 🎨 **Современный интерфейс:**
  - Темная тема CustomTkinter.
  - Динамический индикатор статуса (`● Остановлен` / `● Работает...`).
  - Информативный статус-бар в нижней части окна.
- 🛡 **Надежность и архитектура:**
  - Строгая объектно-ориентированная архитектура (ООП) с разделением слоев GUI и бизнес-логики (`core`).
  - Изолированный рабочий поток (`threading.Thread`, daemon) с мгновенной реакцией на остановку (`threading.Event`).
  - Нулевая искусственная задержка: `pyautogui.PAUSE = 0.0`.
  - Корректное завершение всех фоновых потоков и системных хуков при закрытии окна (`WM_DELETE_WINDOW`).

```text
TBK-Clicker/
├── README.md                    # Документация проекта

        │   ├── __init__.py

            ├── __init__.py
            └── app.py           # Главное окно приложения (CustomTkinter)
```

## 🚀 Установка и запуск из исходного кода

### 1. Клонирование репозитория и переход в папку проекта
```bash
git clone https://github.com/TuBe3rKuL3z/TBK-Clicker.git
cd "TBK-Clicker/TBK-Clicker Project"
```

### 2. Создание и активация виртуального окружения (рекомендуется)
```bash
python -m venv .venv
# Для Windows PowerShell:
.venv\Scripts\Activate.ps1
# Для Windows CMD:
.venv\Scripts\activate.bat
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск приложения
```bash
python main.py
```

## 📦 Сборка в автономный исполняемый файл (.exe)

Для сборки используется **PyInstaller**. Приложение упаковывается в один `.exe` файл без консольного окна.

### Вариант 1. Через скрипт сборки (в один клик)
Запустите файл `build.bat` двойным кликом мыши или из консоли:
```cmd
build.bat
```

### Вариант 2. Вручную через терминал
```bash
pyinstaller --noconsole --onefile --clean --collect-all customtkinter --name "TBK-Clicker" main.py
```

> **Важно:** флаг `--collect-all customtkinter` обязателен, чтобы PyInstaller упаковал встроенные JSON-файлы тем оформления CustomTkinter.

Готовый файл появится в каталоге:
```text
dist/TBK-Clicker.exe
```

## 🎮 Использование

1. Выберите нужную кнопку мыши (**LMB** или **RMB**).
2. Задайте скорость, изменив **Интервал** (в секундах) или **CPS** (кликов в секунду).
3. При необходимости зафиксируйте точку клика:
   - Нажмите **«🎯 Выбрать точку на экране»** и кликните в нужном месте.
   - Или оставьте поля пустыми для кликов в текущей позиции курсора.
4. Нажмите кнопку **«▶ Старт»** в интерфейсе или горячую клавишу **`F5`**.
5. Для остановки нажмите **«⏹ Стоп»** или горячую клавишу **`F6`**.
